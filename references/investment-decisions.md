# 投资决策护栏

仅在买入、卖出、仓位、基金、股票、指数或资产配置决策中读取本文件。先执行主技能的安全、偿付能力、流动性和留在牌桌闸门。

## 买入前的三道闸

按顺序执行，任一不过则结论为 `否` 或 `买入 0 元`。

### 1. 同类替代证伪

把候选与用户当前可持有的最佳同类替代比较。若候选在回报来源、价格、费用、流动性和风险上被替代方案全面压制，不再讨论估值；候选失败。

### 2. 回报引擎与垫子分离

明确真正产生回报的引擎：现金流、盈利增长、估值回归或其他可验证来源。股息、低波动和安全边际只能降低等待成本，不能代替回报引擎。说不清引擎，就不为垫子付钱。

### 3. 自我一致性闸

若买入推翻用户近期的清仓、回避或降配决定，先写清：当时理由错在哪里，或依赖的哪项事实发生了变化。价格变便宜本身不算事实变化；新逻辑必须重新通过前两道闸。

## 仓位与行动

- 市场方向通常比仓位纪律更不确定。优先给出金额、比例上限、流动性底线、停止条件和复核触发点。
- 估值分位只在三道闸通过后参与排序，不自动翻转被回报引擎或一致性否决的结论。
- 新证据只更新它直接支持的变量；同源数据不得重复计数。
- 应急金、短期负债资金和不能承受损失的资金不进入高波动或单一标的实验。
